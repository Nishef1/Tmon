## قوانین خزنده (اجباری)

1. نرخ درخواست محدود و قابل تنظیم برای هر دامنه؛ backoff نمایی.
2. ذخیره پاسخ خام (`raw_payloads` در object storage) قبل از تجزیه، برای بازپردازش.
3. `fetched_at` و `source_url` روی هر رکورد.
4. شرایط استفاده هر سایت پیش از تولید بررسی شود.
5. پایش سلامت: اگر داده روز معاملاتی تا ساعت ۱۳:۳۰ کامل نشد، هشدار.
6. آدرس‌ها و endpointها از دانش عمومی است و در اولین پیاده‌سازی باید با تست یکپارچه تأیید شوند.
