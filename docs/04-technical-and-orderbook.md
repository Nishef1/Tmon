# ۰۴ — تحلیل تکنیکال و تابلوخوانی

در بازاری با دامنه ±۳٪ و بدون فروش استقراضی، **جریان پول و صف** معمولاً از اندیکاتورهای کلاسیک قوی‌ترند. این ادعا فرضیه است و باید با اهمیت ویژگی‌ها (feature importance) در بک‌تست تأیید شود.

## پیش‌نیاز: سری تعدیل‌شده

همه اندیکاتورها روی قیمت **تعدیل‌شده** برای سود نقدی و افزایش سرمایه محاسبه می‌شوند. ضریب تعدیل در هر رویداد:

```
adj_factor = price_after_adjustment / close_before_event
adjusted_price_t = raw_price_t × Π adj_factor (برای همه رویدادهای بعد از t)
```

بدون این، هر مجمع یک «سقوط» جعلی می‌سازد.

## اندیکاتورها

- **روند:** SMA و EMA (۵، ۱۰، ۲۰، ۵۰، ۱۰۰، ۲۰۰)؛ `EMA_t = α·P_t + (1−α)·EMA_{t−1}`، `α = 2/(n+1)`؛ MACD (12، 26، 9)؛ ADX(14)؛ ایچیموکو (9، 26، 52).
- **مومنتوم:** RSI(14) = `100 − 100/(1 + avg_gain/avg_loss)` (Wilder)؛ استوکاستیک (14، 3)؛ Williams %R؛ ROC در ۵، ۱۰، ۲۰ روز.
- **نوسان:** بولینگر (20، 2)، ATR(14)، نوسان تحقق‌یافته ۲۰ روزه.
- **حجم:** OBV، MFI(14)، VWAP روزانه = `Σ(price × vol) / Σ vol`.
- **ساختار:** فاصله از سقف/کف ۲۰ و ۵۲ هفته، شکست با حجم، حمایت/مقاومت (pivot).
- **بازار:** بازده شاخص کل و هم‌وزن، بازده صنعت، نسبت نمادهای مثبت (breadth)، ارزش معاملات خرد کل بازار، ورود پول حقیقی کل بازار.

## ملاحظات ایران

- روزهای صف، «آخرین قیمت» قیمت واقعی تعادل نیست؛ ویژگی `queue_state` باید کنار قیمت باشد.
- دامنه ±۳٪ اندیکاتورهای نوسانی را فشرده می‌کند؛ ویژگی‌ها را نسبت به دامنه مجاز نرمال کنید: `ret / limit_pct`.
- ۹:۰۰ تا ۹:۱۵ پرنوسان‌ترین بازه است؛ ورود D1 بهتر است با قیمت پیش‌گشایش یا پس از ۹:۱۵ شبیه‌سازی شود.
- نمادهای کم‌معامله (میانه ارزش ۲۰ روز پایین) از پیشنهاد حذف می‌شوند ([10](10-recommendation-engine.md)).

## کتابخانه

محاسبه برداری با Polars/NumPy؛ اندیکاتورهای استاندارد با `pandas-ta` یا پیاده‌سازی داخلی تست‌شده در برابر مقادیر مرجع. TA-Lib اختیاری (نیاز به کامپایل C).
