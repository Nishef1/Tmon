# گزارش M3 — baseline قاعده‌محور D1

> **جایگزین شد:** گزارش روی دادهٔ واقعی در [m3-baseline-d1-real.md](m3-baseline-d1-real.md) است. متن زیر یادداشت پیش از دسترسی به TSETMC است و فقط برای سابقه نگه داشته شده.

**وضعیت (قدیمی): روی داده واقعی اجرا نشده است.**

در محیط ساخت این نسخه TSETMC در دسترس نبود (نگاه کنید به `docs/OPEN_QUESTIONS.md`، بندهای مربوط به M1)، پس تاریخچهٔ قیمت و حقیقی/حقوقی دریافت نشده و هیچ عدد واقعی‌ای برای baseline، شاخص هم‌وزن یا صندوق درآمد ثابت وجود ندارد. عددی از بازار واقعی در این مخزن ادعا نمی‌شود.

برای تولید گزارش واقعی پس از اجرای ingestion:

```bash
cd backend
uv run python -m tmon.backtest.cli --md ../docs/reports/m3-baseline-d1-real.md --json ../var/m3.json --html ../var/m3.html
```

آنچه اکنون ثابت شده (روی داده مصنوعی، فقط برای صحت خط لوله):

- [بازار تصادفی بدون لبه](m3-synthetic-random-walk.md): بازده ناخالص هر معامله ≈ صفر و پس از هزینه منفی است؛ یعنی بک‌تستر سود کاذب نمی‌سازد.
- [بازار با لبهٔ کاشته‌شده](m3-synthetic-planted-edge.md): لبه دیده می‌شود (بازده ناخالص و نرخ برخورد به TP بالاتر می‌روند)، ولی با هزینهٔ رفت‌وبرگشت فرض‌شده (حدود ۱٫۸٪) هنوز خالص مثبت نمی‌شود. این هشداری دربارهٔ هزینه‌هاست، نه دربارهٔ بازار واقعی.

هزینه‌ها (کارمزد، مالیات فروش) و حد نوسان با `verified=false` در `market_rules` هستند و تا تأیید با منبع رسمی، همهٔ گزارش‌های بک‌تست باید با این هشدار خوانده شوند.
