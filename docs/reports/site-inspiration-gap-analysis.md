# مقایسهٔ Tmon با سایت‌های مرجع و کمبودهای داده

منبع: ۲۲ تصویر صفحهٔ تابلوخوانی (پوشهٔ Saham روی دسکتاپ) و بازدید از bourse-trader، sahambin و isignal. فقط ایده‌ها؛ هیچ محتوایی کپی نشده است.
نکته: چند تصویر (طلا و نقره، اختیار، اعلان، دیدبان NAV/بنیادی، جزئیات نماد) آن‌قدر عریض‌اند که خواندنی نیستند؛ فقط ساختار کلی‌شان دیده شد.

## آنچه آن سایت‌ها دارند و ما نداریم (با عدد از پایگاه دادهٔ خودمان)

| کمبود | وضعیت ما | اثر بر تحلیل |
|---|---|---|
| دادهٔ لحظه‌ای ۱۰ دقیقه‌ای (پول داغ، پول هوشمند، ورود/خروج حقیقی در ساعت) | `intraday_snapshots` = ۰ ردیف | تمام «شکار سهام» تابلو روی همین ساخته شده؛ ما فقط پایان روز داریم |
| سفارش‌های درشت، سرانه و صف به‌صورت لحظه‌ای، ارزش صف | `order_book_snapshots` = ۰ ردیف | ارزش صف خرید/فروش و «هیجان بازار» ممکن نیست |
| صورت مالی و نسبت‌های بنیادی (P/E، حاشیه سود، رشد فروش) | `codal_reports` = ۱۸ ردیف؛ پشتوانهٔ بنیادی تقریباً صفر | رتبه‌بندی ما فقط قیمت‌محور است؛ سهمِ «ارزان ولی خوب» دیده نمی‌شود |
| نام صنعت و نقشهٔ بازار | `sector_code` برای ۶۵۷۰ از ۶۸۵۲ نماد هست، اما جدول نام گروه نداریم | نمی‌توانیم جریان پول صنعت را معنادار نشان دهیم |
| سقف/کف مجاز قیمت | ستون `limit_up/limit_down` در همهٔ ردیف‌ها خالی | صف خرید/فروش را فقط تقریبی (تغییر ≥ ۲٫۹٪) می‌شود شمرد |
| بازدهٔ سیگنال‌های بسته‌شده و سود/زیان واقعی | سیگنال v1 داریم، ولی دقت زنده هنوز نمونهٔ کافی ندارد | صفحهٔ «معاملات بسته» تابلو بدون این معنا ندارد |
| اختیار معامله، صندوق طلا، NAV لحظه‌ای | فقط `fund_nav` روزانه (۴۷۶ ردیف) | |
| اخبار و فهرست سهامداران عمده | `news_raw` هست اما به صفحه وصل نیست؛ سهامداران نداریم | |

## چرا تحلیل‌های ما ممکن است «آبکی» باشد

1. **فقط چهار سیگنال قیمتی روزانه.** ورودی‌های اصلی رقبا (جریان لحظه‌ای، صف، بنیادی) را نداریم؛ برتری آماری ما در افق ۵ تا ۶۰ روز پیش از هزینه است (IC حدود ۰٫۱) و پس از هزینه دروازهٔ معناداری (G4) نمی‌گذرد.
2. **نبود بنیادی.** بدون سود و ارزش‌گذاری، مدل نمی‌تواند بین «ارزان» و «گران» فرق بگذارد.
3. **داده‌های ناقص روز آخر.** روز آخر برای پول حقیقی فقط ۳ نماد دارد؛ پس صفحهٔ بازار از آخرین روز کامل استفاده می‌کند و تاریخ را جدا می‌نویسد.
4. **قیمت مرجع کهنه.** تغییر بیش از ۵۰٪ در یک روز (مثلاً +۱۹٬۵۴۰٪) از بازگشایی بعد از توقف می‌آید، نه بازده؛ این‌ها از شمارش کنار گذاشته می‌شوند.
5. **صندوق‌ها و نمادهای صف‌دار** در ناحیهٔ خرید قرار می‌گیرند ولی قابل‌خرید نیستند (در صفحهٔ خانه کنار گذاشته می‌شوند).

## بیشترین ارزش با کمترین هزینه (پیشنهاد ترتیب کار)

1. ذخیرهٔ لحظه‌ای: اجرای poller روی `intraday_snapshots` و `order_book_snapshots` از همین امروز؛ هر روز تأخیر یعنی یک روز تاریخچهٔ کمتر برای همیشه.
2. جدول نام گروه‌های صنعت (یک بار از TSETMC).
3. ذخیرهٔ سقف/کف مجاز قیمت هر روز.
4. تکمیل بازیابی Codal برای سبد ۱۰۰تایی (پس از رفع ۴۲۹).
5. اتصال اخبار Codal به صفحهٔ هر نماد.

## آنچه در این مرحله ساخته شد

صفحهٔ `/market` («نمای بازار») با دادهٔ روزانهٔ خودمان: دامنهٔ بازار، توزیع تغییر قیمت، پول حقیقی/حقوقی و سرانه، برترین‌ها، ورود/خروج پول حقیقی و گروه‌های پرمعامله (با کد گروه)، به‌همراه توضیح صریح اینکه چه چیزهایی نمایش داده نمی‌شود.
