# واژه‌نامه (پایه آکادمی سایت)

قالب هر مدخل در سایت: نام فارسی و انگلیسی → تعریف → فرمول → منبع داده → چرا مهم است → مثال → محدودیت در بازار ایران → مدخل‌های مرتبط. مدخل‌های زیر حداقل لازم‌اند؛ فرمول کامل هر کدام در فایل ارجاعی است.

## بازار و معاملات ([01](01-market-structure-and-rules.md))

| واژه | تعریف کوتاه |
| --- | --- |
| نماد | شناسه معاملاتی هر ورقه (مثل «فولاد») |
| کد بورسی / سجام | شناسه سرمایه‌گذار / سامانه احراز هویت |
| بازار اول، دوم، پایه | سطوح پذیرش با الزامات و دامنه متفاوت |
| دامنه نوسان | بیشترین تغییر مجاز روزانه نسبت به قیمت پایانی دیروز |
| قیمت پایانی | میانگین موزون قیمت؛ مبنای دامنه روز بعد |
| قیمت آخرین | قیمت آخرین معامله |
| حجم مبنا | حداقل حجم برای تغییر کامل قیمت پایانی |
| صف خرید/فروش | سفارش‌های انباشته در سقف/کف دامنه |
| پیش‌گشایش، حراج پیوسته، TAL | فازهای روز معاملاتی |
| حقیقی/حقوقی | اشخاص عادی / نهادها |
| تعدیل قیمت | اصلاح قیمت پس از سود نقدی یا افزایش سرمایه |
| T+2 | تسویه دو روز کاری پس از معامله |
| شاخص کل / هم‌وزن | میانگین وزنی بر ارزش بازار / با وزن برابر |
| عرضه اولیه | ورود نخستین سهم شرکت به بازار |

## تابلوخوانی و تکنیکال ([04](04-technical-and-orderbook.md))

سرانه خرید حقیقی، قدرت خریدار حقیقی، ورود پول حقیقی، پول هوشمند، حجم نسبی، عمق سفارش، عدم‌تعادل تابلو، قفل صف، مازاد سالانهٔ خالص، VWAP، SMA، EMA، MACD، RSI، استوکاستیک، بولینگر، ATR، OBV، MFI، ADX، ایچیموکو، حمایت و مقاومت، واگرایی، فیبوناچی.

## بنیادی ([03](03-fundamental-analysis.md))

EPS، P/E، P/B، P/S، DPS، حاشیه سود ناخالص/عملیاتی/خالص، ROE، ROA، نسبت جاری و آنی، بدهی به حقوق صاحبان، جریان نقد عملیاتی، کیفیت سود، گزارش فعالیت ماهانه، رشد واقعی فروش، NAV و P/NAV، DDM، DCF، نرخ تنزیل، تسعیر ارز، نرخ خوراک.

## رویدادها ([05](05-corporate-events.md))

مجمع عمومی عادی/فوق‌العاده، سود نقدی، جدول زمان‌بندی پرداخت، افزایش سرمایه (سود انباشته، تجدید ارزیابی، آورده، صرف سهام)، حق‌تقدم، پذیره‌نویسی، پر شدن شکاف قیمتی.

## صندوق، کالا و آتی ([06](06-funds.md)، [07](07-commodity-and-futures.md))

ETF، صدور و ابطال، NAV صدور/ابطال، حباب صندوق، صندوق درآمد ثابت/سهامی/مختلط/کالایی/اهرمی، گواهی سپرده کالایی، قرارداد آتی، سررسید، وجه تضمین، تسویه روزانه، اخطار افزایش تضمین، basis، آربیتراژ، اختیار خرید/فروش.

## کلان ([08](08-news-and-macro.md))

تورم ماهانه، سالانه، نقطه‌به‌نقطه؛ CPI، PPI؛ نرخ مرکز مبادله، دلار آزاد، نقدینگی M2، نرخ بین‌بانکی، اخزا و YTM، بازده واقعی.

## ریسک و موتور ([10](10-recommendation-engine.md))

احتمال موفقیت کالیبره‌شده، سود مورد انتظار (EV)، حد سود، حد ضرر، triple-barrier، بک‌تست، walk-forward، بیش‌برازش، نوسان، بتا، VaR، حداکثر افت، شارپ، سورتینو، کلی (Kelly)، اندازه پوزیشن، همبستگی، Brier score، کالیبراسیون، SHAP.
