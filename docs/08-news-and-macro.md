# ۰۸ — خبر، مصوبات و داده کلان

متن خام هرگز مستقیم وارد مدل قیمت نمی‌شود. هر خبر به رکورد ساختاریافته `events` تبدیل می‌شود.

## خط لوله

1. **جمع‌آوری:** RSS/خزنده از منابع [02](02-data-sources.md)؛ متن خام + `published_at` دقیق در `news_raw`.
2. **نرمال‌سازی فارسی:** ی/ک عربی، نیم‌فاصله، اعداد فارسی به لاتین (`hazm` یا پیاده‌سازی داخلی).
3. **حذف تکرار:** MinHash یا embedding؛ یک رویداد در ده سایت = یک `event` با چند `source`.
4. **استخراج ساختاریافته با LLM** (خروجی JSON با اسکیما ثابت، اعتبارسنجی با Pydantic):

```json
{
  "event_type": "feedstock_price",
  "symbols": ["شپنا"],
  "sectors": ["petrochemical"],
  "direction": -1,
  "magnitude": 3,
  "confidence": 0.8,
  "effective_from": "2026-11-20",
  "horizon": "M1",
  "is_official": true,
  "summary_fa": "..."
}
```

5. **کالیبراسیون با واکنش بازار:** بازده غیرعادی پس از رویداد ذخیره می‌شود؛ وزن هر `event_type` از داده خودش می‌آید.

```
abnormal_return = r_symbol − (α + β × r_index)
```

## انواع رویداد (فهرست بسته، قابل گسترش)

| `event_type` | مثال | صنایع | جهت معمول |
| --- | --- | --- | --- |
| `fx_rate` | تغییر نرخ مرکز مبادله | صادراتی‌ها | + صادرکننده |
| `feedstock_price` | نرخ گاز خوراک | پتروشیمی، اوره، فولاد | − |
| `price_control` | سقف قیمت خودرو/دارو/لبنیات | خودرو، دارو، غذایی | − |
| `tax_tariff` | عوارض صادرات، مالیات | گروه هدف | − |
| `interest_rate` | نرخ بین‌بانکی، اخزا | کل بازار؛ بانک‌ها | − سهام / + بانک |
| `geopolitical` | جنگ، آتش‌بس، مذاکره، تحریم | کل بازار | متغیر |
| `regulator` | تغییر دامنه، توقف، حمایت صندوق تثبیت | کل بازار | متغیر |
| `company_disclosure` | قرارداد، توقف تولید، حادثه | نماد | متغیر |
| `energy_restriction` | قطع برق/گاز صنایع | فولاد، سیمان، پتروشیمی | − |

## ویژگی‌های خبری برای موتور

برای هر نماد و روز: `news_sentiment_1d`, `news_sentiment_5d` (میانگین وزنی `direction × magnitude × confidence` با زوال نمایی)، `has_official_event`, `market_geo_risk` (سطح کل بازار).

## سری‌های کلان (`macro_series`)

تورم ماهانه/سالانه/نقطه‌ای (منبع جدا)، دلار آزاد، مرکز مبادله، اونس، برنت، فولاد، مس، اوره، متانول، YTM اخزا، نقدینگی M2. ویژگی‌ها: تغییر ۵، ۲۰ و ۶۰ روزه.

قانون point-in-time: داده کلان با `release_date` (روز انتشار) ذخیره می‌شود، نه ماه مرجع؛ تورم مهر قبل از ۶ آبان در دسترس مدل نیست.
